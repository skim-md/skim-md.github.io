Lire vos fichiers Markdown, pas les déchiffrer

Skim est une visionneuse Markdown gratuite pour Chrome, Edge, Brave, Opera et Firefox.

Un fichier .md, c'est du texte avec quelques symboles comme # et **. Dans le navigateur, on voit d'habitude ces symboles tels quels. Avec Skim, vous ouvrez le fichier comme d'habitude et vous obtenez une vraie page : titres, tableaux, code coloré, sommaire sur le côté.

Pensé pour ce qu'écrivent les agents IA

Claude Code, Cursor et Codex écrivent leurs plans et leurs rapports en Markdown. Laissez le plan.md ouvert dans un onglet : Skim le réaffiche à chaque sauvegarde, sans recharger, et garde votre position.

Ce que fait Skim

  • Fichiers locaux : double-clic sur un .md, c'est tout. Un réglage à activer une seule fois, Skim vous montre où.
  • Formules et diagrammes : LaTeX avec KaTeX et Mermaid, même hors ligne.
  • Vue dossier : ouvrez un dossier et parcourez tous ses fichiers Markdown.
  • Export : en PDF ou en fichier HTML autonome.
  • Aucune donnée : pas de pistage, pas de compte. Code sous licence MIT sur GitHub.

Installer

  1. Chrome, Edge, Brave, Opera, Vivaldi ou Arc : Skim sur le Chrome Web Store. Firefox : Skim sur Firefox Add-ons.
  2. Pour les fichiers locaux, autorisez l'accès une fois. Skim vous guide.
  3. Désormais, chaque fichier .md s'ouvre comme une page mise en forme.

Un seul fichier, rien à installer ? Glissez-le dans la visionneuse en ligne. Tout se passe dans votre navigateur, rien n'est envoyé.

Questions fréquentes

Skim est-il payant ?

Non. Toutes les fonctions sont gratuites, il n'y a pas de version Pro.

Ça marche sous Windows et Mac ?

Oui. Skim tourne dans le navigateur, donc partout où Chrome, Edge ou Firefox fonctionnent.
