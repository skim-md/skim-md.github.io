Markdown-Dateien im Browser lesen, nicht entziffern

Skim ist ein kostenloser Markdown-Viewer für Chrome, Edge, Brave, Opera und Firefox.

Eine .md-Datei ist Text mit ein paar Zeichen wie # und **. Im Browser siehst du normalerweise genau diese Zeichen. Mit Skim öffnest du die Datei wie immer und bekommst eine richtige Seite: Überschriften, Tabellen, Code mit Farben, ein Inhaltsverzeichnis an der Seite.

Gebaut für das, was KI-Agenten schreiben

Claude Code, Cursor und Codex schreiben ihre Pläne und Berichte als Markdown. Lass die plan.md in einem Tab offen: Skim rendert sie bei jedem Speichern neu, ohne Neuladen, und deine Scrollposition bleibt, wo sie war.

Was Skim kann

  • Lokale Dateien: Doppelklick auf eine .md-Datei, fertig. Ein einmaliger Schalter, Skim zeigt dir genau wo.
  • Formeln und Diagramme: LaTeX mit KaTeX und Mermaid, auch offline.
  • Ordneransicht: einen Ordner öffnen und durch alle Markdown-Dateien klicken.
  • Export: als PDF oder als eigenständige HTML-Datei.
  • Keine Daten: kein Tracking, keine Konten. Der Code steht unter MIT-Lizenz auf GitHub.

Installieren

  1. Chrome, Edge, Brave, Opera, Vivaldi oder Arc: Skim im Chrome Web Store. Firefox: Skim bei Firefox Add-ons.
  2. Für lokale Dateien einmal den Zugriff erlauben. Skim führt dich hin.
  3. Jede .md-Datei öffnet sich ab jetzt als formatierte Seite.

Nur eine Datei, nichts installieren? Zieh sie in den Online-Viewer. Er läuft komplett in deinem Browser, nichts wird hochgeladen.

Häufige Fragen

Kostet Skim etwas?

Nein. Alle Funktionen sind kostenlos, es gibt keine Pro-Version.

Funktioniert Skim mit Windows und Mac?

Ja. Skim läuft im Browser, also überall, wo Chrome, Edge oder Firefox laufen.

Markdown einfach lesen. Skim kostenlos hinzufügen oder den Online-Viewer ausprobieren.
