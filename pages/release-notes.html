What's new in Skim

Updated 3 August 2026

Every change that reaches the markdown viewer, newest first. 3 minute read.

Skim is a free, open source markdown viewer for the browser. This page tracks what each release adds, so you can tell at a glance whether the version you have is the one being described. Updates arrive automatically from your browser's extension store, usually within a day of publication.

Version 2.2 3 August 2026

The reading release

2.2 is about what happens after a file renders: how it looks, how you move through it, and how you get it back out. Seven changes, all free, all on-device.

  • Themes and color schemes Look

    Light and dark are joined by six color schemes, so a document can be tuned to the room you are reading in rather than to whatever the extension shipped with. Pick a base brightness, then a palette on top: grape, rosé, ocean, sunset, forest, or mono. Mono is deliberately black and white, which is what you want when the page is headed for a printer.

    Your choice syncs across every device signed into the same browser profile, and applies the moment you pick it in any open tab.

    • None
    • Grape
    • Rosé
    • Ocean
    • Sunset
    • Forest
    • Mono

  • Zen mode Look

    One button hides the contents sidebar and centers the column, leaving the document and nothing else. It is the right mode for a long read, a narrow window, or a screen share where the sidebar is just noise. Press it again and the sidebar comes back exactly as it was.

  • Better PDF export Export

    Exporting to PDF is now a real print layout rather than a screenshot of a dark theme. Skim prints on white with proper page breaks, keeps headings with the text that follows them, prints link targets where they matter, and can add a numbered table of contents to the front. Page margins are yours to set: none, narrow, normal, or wide.

    Ctrl or Cmd plus P is intercepted so the browser's own print dialog gets the export layout too, which means the PDF looks the same whichever route you take. See the full walkthrough in convert markdown to PDF.

  • Better HTML export Export

    Export the document as a single self-contained .html file. Fonts, styles, math and diagrams are embedded in the file itself, so it opens correctly on a machine that has never heard of Skim, with no network access and nothing to install. The current theme, color scheme and reading density travel with it.

    • document.pdf print layout, margins, optional contents
    • document.html one file, everything inlined, opens anywhere

  • Better navigation Reading

    The contents sidebar highlights the section you are actually in as you scroll, and every heading has a copyable anchor link. Tab and Shift plus Tab step through the document block by block, table row by table row, with the current block marked in the margin, so a long document can be read start to finish without touching the mouse.

    Wide tables and images size themselves to the column instead of overflowing it, and internal links scroll smoothly to their target rather than jumping.

  • Vim navigation Reading

    If your hands live on the home row, they can stay there. j and k scroll by one rendered line with eased motion, so holding a key glides instead of stuttering. G jumps to the end of the document and gg to the start. Esc clears the reading cursor.

    None of it fires while you are typing in a field or when a modifier is held, and all of it respects the reduced-motion setting in your operating system.

    • jk scroll a line
    • gg top
    • G bottom
    • Tab next block
    • Esc clear

  • Clipboard markdown viewer New

    Copy markdown from anywhere, a chat with Claude or ChatGPT, a code review, a terminal, then click Render clipboard as MD in the Skim toolbar popup. It opens in a new tab as a fully rendered page, with the same theme, contents sidebar, export buttons and keyboard navigation as a real file. Nothing is saved to disk and nothing is uploaded.

    Reload that tab and it re-reads your clipboard, so it doubles as a scratch pad: copy, refresh, read. If your browser will not hand the clipboard over, the page accepts a plain Ctrl or Cmd plus V instead.

How to update

Extensions update themselves. Chrome, Edge, Brave, Opera, Vivaldi and Arc check the Chrome Web Store every few hours; Firefox checks Firefox Add-ons on its own schedule. To force it in a Chromium browser, open chrome://extensions, turn on Developer mode, and click Update. In Firefox, open about:addons, click the gear icon, and choose "Check for Updates".

To see which version you have, open chrome://extensions or about:addons and read the number under Skim.

FAQ

Is Skim still free after these updates?

Yes. Every feature on this page is free and MIT open source, including themes, zen mode, PDF and HTML export, and the clipboard viewer. There is no Pro tier and no account.

Do I need to do anything to get the new version?

No. Your browser updates extensions automatically, usually within a day. You can force a check from the extensions page if you would rather not wait.

Does the clipboard viewer send my clipboard anywhere?

No. The clipboard is read in the extension and rendered in a local tab on your device. Nothing is uploaded, and nothing is written to disk.

Where can I see the full commit history?

Skim is developed in the open. Every change, including the small ones that do not appear here, is on GitHub under the MIT license.
