Leia seus arquivos Markdown, sem decifrar

O Skim é um visualizador de Markdown grátis para Chrome, Edge, Brave, Opera e Firefox.

Um arquivo .md é texto com alguns símbolos como # e **. No navegador, você normalmente vê esses símbolos do jeito que estão. Com o Skim, você abre o arquivo como sempre e vê uma página de verdade: títulos, tabelas, código colorido e um sumário na lateral.

Feito para o que os agentes de IA escrevem

Claude Code, Cursor e Codex escrevem planos e relatórios em Markdown. Deixe o plan.md aberto numa aba: o Skim mostra a versão nova a cada salvamento, sem recarregar, e mantém a sua posição na página.

O que o Skim faz

  • Arquivos locais: dois cliques num .md e pronto. Uma permissão que você ativa uma vez só, e o Skim mostra onde.
  • Fórmulas e diagramas: LaTeX com KaTeX e Mermaid, inclusive offline.
  • Visão de pasta: abra uma pasta e navegue por todos os arquivos Markdown dela.
  • Exportar: para PDF ou para um arquivo HTML independente.
  • Zero dados: sem rastreamento e sem conta. Código com licença MIT no GitHub.

Como instalar

  1. Chrome, Edge, Brave, Opera, Vivaldi ou Arc: Skim na Chrome Web Store. Firefox: Skim no Firefox Add-ons.
  2. Para arquivos locais, permita o acesso uma vez. O Skim guia você.
  3. A partir daí, todo arquivo .md abre como uma página formatada.

Só um arquivo e nada para instalar? Arraste para o visualizador online. Tudo roda no seu navegador, nada é enviado.

Perguntas frequentes

O Skim é pago?

Não. Todas as funções são grátis e não existe versão Pro.

Funciona no Windows e no Mac?

Sim. O Skim roda dentro do navegador, então funciona onde o Chrome, o Edge ou o Firefox funcionam.
